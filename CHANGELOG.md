# Changelog

## 0.1.0

Initial local product release: Docker Compose PostgreSQL, durable source/job management, offline hybrid retrieval and reranking, authenticated dashboard, Cosmograph exploration, Codex skills/MCP integration, fictional demo, operating manuals and allowlisted release packaging.

Support scope is single-owner Linux. Native Windows/macOS, hosted multi-user access, automatic retention and cross-path restore are outside this release.
